# Recruitment message (template)

Use as-is or adapt the tone for your group chat / department mailing list.

---

Hi! I'm collecting short practice-presentation recordings for my final-year
thesis project on an AI presentation coach — would really appreciate 10-15
minutes of your time.

What it involves:
- Reading out 5 short scripts (30s-2min each — a news clip, a flight
  announcement, an ad, an academic intro, and a short speech) in front of
  your laptop camera, using a practice tool I built
- No prep needed, scripts are provided, you can redo any one if you mess up
- Your name is never stored — you're just assigned a code like "p007"
- Recordings are used only for this academic project, not shared publicly

Takes about 10-15 minutes total. If you're up for it, I'll send you a link
and a quick consent form. Thanks so much — this genuinely can't happen
without a few people willing to do this!

---

Practical tips for running this smoothly:
- Do it in person with your laptop if you can — easier to help with camera/
  mic permission prompts and to answer questions than doing it remotely.
- Batch 2-3 people per sitting if possible so it doesn't drag out over weeks.
- Send the consent form (`consent_form_template.md`) before recording, not after.
