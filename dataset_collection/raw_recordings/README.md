# raw_recordings/

Empty on purpose. Populate it as:

```
raw_recordings/
  p001/
    academic/
      attempt1/
        audio.wav
        video.mp4
        transcript.txt
        script.txt
    news/
      attempt1/
        ...
  p002/
    ...
```

Then run `../scripts/ingest.py`. See `../PROTOCOL.md` for the full process.
